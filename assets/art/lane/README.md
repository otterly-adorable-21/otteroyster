# Otter Lane

Transparent.

Upload files named exactly like the **File name** column, plus the extension
(`.png` is best: it also works in Shelly's Discord pictures. `.webp` and animated `.gif` work on the website), e.g. `house.png`. Use lowercase.
The website picks them up a minute or two after you upload. Until then, and for
any spot left empty, the drawn version stays.

| | File name | What | Size (px) | Notes |
| --- | --- | --- | --- | --- |
| ⬜ | `house` | House front | 480 × 520 | Each player's otter stands on the porch, bottom right |
| ⬜ | `street` | Street background | 1600 × 640 |  |
