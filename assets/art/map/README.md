# World map

The whole map is 1600 × 1840 px. Place pins stay on top at the same spots, so keep each place where it is on the current map.

Upload files named exactly like the **File name** column, plus the extension
(`.png` is best: it also works in Shelly's Discord pictures. `.webp` and animated `.gif` work on the website), e.g. `world.png`. Use lowercase.
The website picks them up a minute or two after you upload. Until then, and for
any spot left empty, the drawn version stays.
