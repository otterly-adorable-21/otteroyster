# Garden crops

Transparent. Each crop has a seed-packet icon (256 × 256) and growth stages (320 × 400, plant standing on the bottom edge): -0 planted seed, -1 sprout, -2 growing, -3 ready to harvest.

Upload files named exactly like the **File name** column, plus the extension
(`.png` is best: it also works in Shelly's Discord pictures. `.webp` and animated `.gif` work on the website), e.g. `sprouts.png`. Use lowercase.
The website picks them up a minute or two after you upload. Until then, and for
any spot left empty, the drawn version stays.
