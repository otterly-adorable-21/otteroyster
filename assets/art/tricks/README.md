# Tricks

256 × 256 px.

Upload files named exactly like the **File name** column, plus the extension
(`.png` is best: it also works in Shelly's Discord pictures. `.webp` and animated `.gif` work on the website), e.g. `rollover.png`. Use lowercase.
The website picks them up a minute or two after you upload. Until then, and for
any spot left empty, the drawn version stays.

| | File name | What | Size (px) | Notes |
| --- | --- | --- | --- | --- |
| ⬜ | `rollover` | 🔄 Roll over | 256 × 256 |  |
| ⬜ | `juggle` | 🪨 Juggle a pebble | 256 × 256 |  |
| ⬜ | `handstand` | 🤸 Handstand | 256 × 256 |  |
| ⬜ | `twirl` | 🌀 Water twirl | 256 × 256 |  |
