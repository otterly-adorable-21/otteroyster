# Trinkets

Collectible trinkets, 256 × 256 px, transparent. They also appear inside the den display cases.

Upload files named exactly like the **File name** column, plus the extension
(`.png` is best: it also works in Shelly's Discord pictures. `.webp` and animated `.gif` work on the website), e.g. `seaglassbit.png`. Use lowercase.
The website picks them up a minute or two after you upload. Until then, and for
any spot left empty, the drawn version stays.
