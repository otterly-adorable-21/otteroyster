# Garden

The garden outside the den.

Upload files named exactly like the **File name** column, plus the extension
(`.png` is best: it also works in Shelly's Discord pictures. `.webp` and animated `.gif` work on the website), e.g. `background.png`. Use lowercase.
The website picks them up a minute or two after you upload. Until then, and for
any spot left empty, the drawn version stays.

| | File name | What | Size (px) | Notes |
| --- | --- | --- | --- | --- |
| ⬜ | `background` | Garden background | 1600 × 1200 | Plots sit in 2 rows of 3 on top; keep the lower two-thirds fairly plain |
| ⬜ | `plot` | Soil plot (dry) | 400 × 120 | transparent |
| ⬜ | `plot-wet` | Soil plot (watered) | 400 × 120 | transparent |
