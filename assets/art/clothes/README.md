# Clothes

Transparent, 800 × 1016 px, on the same canvas as the otter: draw only the item, in the spot it sits on the otter. Shop cards crop to the item automatically.

Upload files named exactly like the **File name** column, plus the extension
(`.png` is best: it also works in Shelly's Discord pictures. `.webp` and animated `.gif` work on the website), e.g. `partyhat.png`. Use lowercase.
The website picks them up a minute or two after you upload. Until then, and for
any spot left empty, the drawn version stays.
