# Front door

Transparent, 480 × 520 px: the same canvas as the Otter Lane house (lane/house). Draw only the piece, in the spot it goes on the house, so the pieces stack. Paint layers are the door itself.

Upload files named exactly like the **File name** column, plus the extension
(`.png` is best: it also works in Shelly's Discord pictures. `.webp` and animated `.gif` work on the website), e.g. `paint-moss.png`. Use lowercase.
The website picks them up a minute or two after you upload. Until then, and for
any spot left empty, the drawn version stays.
