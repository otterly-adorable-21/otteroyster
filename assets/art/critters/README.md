# Pond wildlife

Little animals that wander across the pond scene, 128 × 128 px, transparent, facing right. Animated GIF/WebP works great.

Upload files named exactly like the **File name** column, plus the extension
(`.png` is best: it also works in Shelly's Discord pictures. `.webp` and animated `.gif` work on the website), e.g. `firefly.png`. Use lowercase.
The website picks them up a minute or two after you upload. Until then, and for
any spot left empty, the drawn version stays.
