# The otter

Transparent PNG/WebP, 800 × 1016 px. Every otter picture and every clothing layer uses this same canvas, so they line up when stacked: keep the otter centered with its feet near the bottom, the same spot in every pose. A template with guide lines is at assets/art/otter/_template.png.

Upload files named exactly like the **File name** column, plus the extension
(`.png` is best: it also works in Shelly's Discord pictures. `.webp` and animated `.gif` work on the website), e.g. `base.png`. Use lowercase.
The website picks them up a minute or two after you upload. Until then, and for
any spot left empty, the drawn version stays.
