# Pet companions

Transparent, 512 × 512 px, the companion standing on the bottom edge, facing right. Optional sleeping pose: <id>-sleeping. Color skins: <id><color> (e.g. axolotlnavy), same pose; each companion has its own list of colors (js/companions.js COMP_SKINS). Companions without skins get tinted colors.

Upload files named exactly like the **File name** column, plus the extension
(`.png` is best: it also works in Shelly's Discord pictures. `.webp` and animated `.gif` work on the website), e.g. `duckling.png`. Use lowercase.
The website picks them up a minute or two after you upload. Until then, and for
any spot left empty, the drawn version stays.
