# Den furniture

Transparent PNG/WebP at the size shown (4× the den size). The bottom edge of the picture is where it sits on the floor or wall.

Upload files named exactly like the **File name** column, plus the extension
(`.png` is best: it also works in Shelly's Discord pictures. `.webp` and animated `.gif` work on the website), e.g. `shellbed.png`. Use lowercase.
The website picks them up a minute or two after you upload. Until then, and for
any spot left empty, the drawn version stays.
