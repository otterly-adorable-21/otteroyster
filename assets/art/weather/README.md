# Weather overlays

Transparent, 1080 × 1000 px, drawn over the pond. Animated WebP/GIF works great here.

Upload files named exactly like the **File name** column, plus the extension
(`.png` is best: it also works in Shelly's Discord pictures. `.webp` and animated `.gif` work on the website), e.g. `sunny.png`. Use lowercase.
The website picks them up a minute or two after you upload. Until then, and for
any spot left empty, the drawn version stays.

| | File name | What | Size (px) | Notes |
| --- | --- | --- | --- | --- |
| ⬜ | `sunny` | ☀️ Sunny | 1080 × 1000 |  |
| ⬜ | `cloudy` | ⛅ Cloudy | 1080 × 1000 |  |
| ⬜ | `rainy` | 🌧️ Rainy | 1080 × 1000 |  |
| ⬜ | `misty` | 🌫️ Misty | 1080 × 1000 |  |
| ⬜ | `breezy` | 🍃 Breezy | 1080 × 1000 |  |
