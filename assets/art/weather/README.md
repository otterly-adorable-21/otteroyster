# Weather overlays

Transparent, 1600 × 1000 px, drawn over the pond and the otter (rain falls in front). Animated WebP works best (send numbered transparent PNG frames and they can be built with tools/weather). Each one replaces the built-in effect for that weather.

Upload files named exactly like the **File name** column, plus the extension
(`.png` is best: it also works in Shelly's Discord pictures. `.webp` and animated `.gif` work on the website), e.g. `sunny.png`. Use lowercase.
The website picks them up a minute or two after you upload. Until then, and for
any spot left empty, the drawn version stays.

| | File name | What | Size (px) | Notes |
| --- | --- | --- | --- | --- |
| ✅ | `sunny` | ☀️ Sunny | 1600 × 1000 |  |
| ✅ | `cloudy` | ⛅ Cloudy | 1600 × 1000 |  |
| ✅ | `rainy` | 🌧️ Rainy | 1600 × 1000 |  |
| ✅ | `misty` | 🌫️ Misty | 1600 × 1000 |  |
| ✅ | `breezy` | 🍃 Breezy | 1600 × 1000 |  |
