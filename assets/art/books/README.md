# Storybooks

Book covers for the bookshelf, portrait, 240 × 320 px (3:4). They show as covers on the shelf and next to the story when it is read.

Upload files named exactly like the **File name** column, plus the extension
(`.png` is best: it also works in Shelly's Discord pictures. `.webp` and animated `.gif` work on the website), e.g. `tidepoet.png`. Use lowercase.
The website picks them up a minute or two after you upload. Until then, and for
any spot left empty, the drawn version stays.
